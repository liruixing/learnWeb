# 技术栈与运行说明

## 项目类型

本项目是一个基于 Kotlin 的 Spring Boot 后端工程，使用 Gradle Wrapper 作为构建和运行入口。

## 核心技术栈

- 语言：Kotlin
- JVM 版本：Java 25
- 框架：Spring Boot 4.0.6
- 构建工具：Gradle 9.5.1，项目内置 `gradlew` / `gradlew.bat`
- Gradle 插件：
  - `org.springframework.boot`
  - `io.spring.dependency-management`
  - `kotlin("jvm")`
  - `kotlin("plugin.spring")`
- 测试框架：JUnit 5、Kotlin Test
- 项目入口：`src/main/kotlin/com/dennis/learn/LearnApplication.kt`

## 推荐 IDE

推荐使用 IntelliJ IDEA。

原因：

- 对 Kotlin、Gradle、Spring Boot 支持最完整。
- 可以直接识别 `build.gradle.kts`。
- 可以自动配置 Gradle 项目、Kotlin 插件和 Spring Boot 启动入口。

可选 IDE：

- Visual Studio Code：需要安装 Kotlin、Extension Pack for Java、Spring Boot Extension Pack 等插件，配置成本更高。
- Android Studio：底层也基于 IntelliJ 平台，可以打开 Gradle/Kotlin 项目，但它主要面向 Android 开发，不是此类后端项目的首选。

## 本地环境要求

运行前需要准备：

1. 安装 JDK 25。
2. 确认命令行可以访问 Java：

   ```bash
   java -version
   ```

3. 不需要单独安装 Gradle。项目已经包含 Gradle Wrapper，直接使用 `./gradlew` 即可。

macOS / Linux 使用：

```bash
./gradlew <task>
```

Windows 使用：

```bat
gradlew.bat <task>
```

## 使用 IntelliJ IDEA 运行

1. 打开 IntelliJ IDEA。
2. 选择 `Open`，打开项目根目录：

   ```text
   /Volumes/app/06SelfProject/learnWeb/learn
   ```

3. 等待 IDEA 自动导入 Gradle 项目。
4. 确认 Project SDK 使用 JDK 25：
   - `File` -> `Project Structure` -> `Project`
   - `SDK` 选择 JDK 25
5. 打开入口文件：

   ```text
   src/main/kotlin/com/dennis/learn/LearnApplication.kt
   ```

6. 点击 `main` 函数旁边的运行按钮，或创建 Spring Boot 运行配置。
7. 启动类为：

   ```text
   com.dennis.learn.LearnApplicationKt
   ```

## 使用命令行运行

在项目根目录执行：

```bash
./gradlew bootRun
```

该命令会：

1. 使用 Gradle Wrapper 下载或使用本地 Gradle 9.5.1。
2. 编译 Kotlin 源码。
3. 启动 Spring Boot 应用。

如果只是验证项目可以编译：

```bash
./gradlew build
```

如果只运行测试：

```bash
./gradlew test
```

## 当前应用配置

配置文件位置：

```text
src/main/resources/application.properties
```

当前配置内容：

```properties
spring.application.name=learn
```

当前依赖只包含 `spring-boot-starter`，没有引入 `spring-boot-starter-web`，因此项目不是一个 Web 服务项目，默认不会提供 HTTP 端口。如果后续需要提供 REST API，需要在 `build.gradle.kts` 中增加 Web 依赖：

```kotlin
implementation("org.springframework.boot:spring-boot-starter-web")
```

然后再通过 `./gradlew bootRun` 启动。

## 常见问题

### 1. `java -version` 不是 25

需要安装 JDK 25，并让 `JAVA_HOME` 指向 JDK 25。

macOS 可以检查：

```bash
/usr/libexec/java_home -V
```

### 2. IDEA 导入后 Kotlin 或 Gradle 报错

优先执行：

```bash
./gradlew build
```

如果命令行能构建成功，通常是 IDE SDK 或 Gradle JVM 配置不一致。需要在 IDEA 的 Gradle 设置中把 Gradle JVM 改为 JDK 25。

### 3. 第一次运行很慢

第一次执行 `./gradlew bootRun` 或 `./gradlew build` 时，Gradle 需要下载依赖和 Wrapper 发行包，耗时较长是正常现象。后续会使用本地缓存。
